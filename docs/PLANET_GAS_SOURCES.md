# 巨行星内容与图片记录

核验日期：2026-10-06。适用代码：`src/exploration/planetStoriesGas.ts`。

本批保留原有 8 个入口，新增木星赤道云带、木星极地气旋、土星北极六边形、土星 C 环代表性观测区、海王星风暴活动，共 13 个科学故事、26 个图库引用、17 张不同真实 JPEG。木星 4 个入口、土星 4 个、天王星 2 个、海王星 3 个。图片可在同一星球内作明确标注的上下文复用；同一入口的两张图始终不同，不复制一张照片制造切换。自动来源核验与人工审核分开：13 个故事均为 `humanReview: pending`，人工审定数量为 0。

## 位置与关系核验

- 巨行星 `cloud` / `phenomenon` 标签是代表入口，不是固定地表位置。经度由展示布局选取，不声称对应当前漂移风暴或纹理中的精准地物。木星极地气旋入口在北极附近但面板对比南北两极；海王星风暴入口的 -50° / -70° 不作为 D2 的真实测定位置。
- 大红斑纬度取约南纬 22 度作为示意。纬度量测有 planetographic / planetocentric 的区别，本项目使用球面示意模型，不做两种坐标的精确互换或测绘承诺。约 22°S 的观测背景见 [NASA NTRS 涡旋研究](https://ntrs.nasa.gov/citations/20210022719)。
- 土星仅复用已有环几何，绑定其倾斜环面（现有 Euler 为 0.5 / 0 / -0.3）；土星环、卡西尼缝、C 环入口分别为示意半径 1.7 / 1.925 / 1.5、角度 25° / 115° / 225°，都在现有 1.35–2.43 模型环范围内。这些参数不是千米值、不验证实际缝宽，也不保证 A/B/C 环边缘的真实比例。
- 天王星 `region-uranus-rings` 使用 `phenomenon`。当前没有重建实体环；球面标签仅打开真实环系图文。不能宣称已完成三维环几何。
- NASA Photojournal 的 `Image Addition Date` 是入库时间，不是拍摄时间。日期不明的图片只使用已核验的飞越年份，并在每张图记录中保留判断依据，不编造拍摄日。
- PIA24967 的源页正文称对比年份为 2016 / 2021，原图左栏却标有 Feb. 2017 / 2017-02-02，右栏为 Oct. 2021 / 2021-10-16。图库日期使用无冲突的最新观测年 `2021`，图注和机器记录明确保留此分歧，待人工复核；不自行修改原图日期。
