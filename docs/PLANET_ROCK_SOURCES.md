# Rocky Planet Stories: Source and Media Audit

Checked 2026-10-06. This pack adds eleven regional stories to the existing SOLARIS gallery contract, without changing legacy Mars content, gesture controls or map services. It provides 22 distinct JPEGs: 20 new local files and two reused existing assets. Mercury has two entries, Venus five, Mars four. All `humanReview` fields remain `pending`; automated source checks are not the user's editorial approval.

All positions are schematic regional anchors, not landing-navigation coordinates or proof of pixel-perfect registration to the existing globe textures. Planetographic and planetocentric definitions can differ; no unsupported datum transformation is claimed. The UI must not represent these photographs as a real-time terrain service.

## Media Rights

Each specific caption, complete mission credit, acquisition or release date and downloaded file was checked separately. The selected source captions do not identify a separate copyright-protected owner notice. Partner credits such as JHUAPL, Carnegie, USGS and MSSS are retained exactly; they are not silently relabeled NASA-only.

The reuse basis is the current [NASA educational/informational media guidance](https://www.nasa.gov/nasa-brand-center/images-and-media/) and [JPL image-use policy](https://www.jpl.nasa.gov/jpl-image-use-policy/), with full attribution and no implied endorsement. This is **not** an assertion that all NASA website material is public domain. JPL identifies educational/personal reuse of some third-party imagery separately from commercial use. Advertising, merchandise or third-party commercial rights are not cleared by this pack.

The former MESSENGER-specific image-policy link (`https://messenger.jhuapl.edu/the_mission/image_use.html`) currently returns 404 in the independent network check. This retired page has not been recovered or quoted as a current license. The pack records the functioning NASA/JPL educational reuse guidance instead; further commercial clearance would require an owner-specific check. All final human review is still pending.

Excluded: PIA10359 and PIA11077, whose captions carry Science/AAAS reproduction or figure notices. No assumption was made that a NASA page overrides that external permission. No downloaded image is AI-generated. Source scientific renderings are labeled as such.

The `PIA00563` resource page does not display a credit table. The independent [NASA Viking 50-years gallery](https://science.nasa.gov/mission/viking/viking-50-years-on-mars/) identifies the same PIA number as NASA/JPL. Some old image alternative text misstates 1997; the resource's Historical Date and body establish July 21, 1976. The code does not reproduce the erroneous date.

All 22 files were decoded and visually inspected in a local contact sheet. Their hashes are unique. Pixel dimensions are **not** geographic resolution, and historic imagery does not imply complete coverage or contemporary surface detail. This pack does not add live imagery tiles, terrain, buildings, a surface mesh or globe-texture registration. Those capabilities require separate integration and evidence.

Eleven oversized new files now use NASA's official `assets.science.nasa.gov/dynamicimage/` proportional size variants with `fit=clip&w=1280&h=1280`. The table above preserves their original source dimensions, not the final bundled sizes. The agency's actual responses have a longest edge of 1280; integer rounding is recorded exactly. No local crop, recoloring, AI redraw or synthetic enhancement was applied. Original source download URL, dimensions, byte count and SHA-256 are retained in `original*` manifest fields, distinct from the bundled file's actual values. Using smaller display files does not claim the source's native geographic resolution.

## Checks and Remaining Review

Focused tests cover the eleven IDs/body assignments, two distinct images per region, valid event image indices and primary sources, local JPEG signatures, byte counts/hashes, complete rights/date metadata, proportional official-size variants with separate original dimensions, east/west conversion and control-network labels, explicit radar-rendering disclosures, legacy asset identity and landing-history qualifications. Whole-scene desktop, gesture, mobile and Fire TV tests remain the root task's integration work.

Before final competition submission, a human should review the Chinese/English wording and rights limits, especially educational versus commercial use and the retired MESSENGER policy link. This first requested set has no empty added entries; wider rocky-planet content beyond these eleven places is not represented as complete.
