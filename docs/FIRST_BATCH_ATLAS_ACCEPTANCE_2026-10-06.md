# SOLARIS 首批统一星球标注验收

日期：2026-10-06。范围是首批可演示、可扩展的轻量星球标注，不是世界全部城市，也不是街道级 Google Earth。保留当前太阳系、原星球模型、手势识别与已有未提交工作；本轮没有 commit、push 或公开部署。

地球首批有 6 个大洲导航组、31 个国家／地区导航组。中国组按用户清单包括北京、上海、深圳、杭州、香港、台北；这是产品内容分组，不从分组推导行政地位或首都关系。中国组的首都标记只取北京。俄罗斯两城按城市所在地归欧洲，不把整个俄罗斯划为欧洲。

## 共用能力与状态

- 沿用原 R3F Canvas、`PlanetBase` 与太阳系相机；没有另造一个地球模型，也没有用普通详情页替换当前背景。
- 8 行星均支持缓慢自转、鼠标拖动俯仰／转动及缩放；手动操作可暂停自转，按钮可恢复。
- 通用 `PlanetAnnotations` 使用圆点／圆圈、折线引导和文字标签。投影来自星球完整世界矩阵，处理球背遮挡、屏幕边界和标签碰撞，不写死屏幕坐标。
- 地球保留 Natural Earth 国家轮廓；大洲、国家／地区、城市、城市内地点是内容选择层，不新增局部街道模型。
- 城市选择或热点聚焦只旋转到目标、突出标签，不自动打开图文。主动点击标注才进入玻璃面板。
- `GlobeStoryPanel` 共享半透明背景、模糊与高光，照片和文字本身不模糊；支持上一张、下一张、缩略图和对应事件图片选择。
- 模态归属仍是 `PLANET_OVERVIEW → INFO_PANEL_OPEN → PLANET_OVERVIEW`；城市范围 `scopeCityId` 只管理注解集合，不另抢相机控制权。
- 关闭图文不写相机、Euler 或缩放；返回动画可用 ESC／BACK 中断并恢复稳定行星状态。既有手势识别算法没有改写。

## 来源与审核边界

事实、地点关系、照片许可、照片中附加作品权利和用户人工审核分开记录。全部 `humanReview` 仍为 `pending`，人工通过 0 条；机器辅助来源核验不能宣传为用户人工审核或全球商业清权完成。

58 地标均有第一方事实链接和 Wikidata 坐标证据。116 张地标摄影素材分别核对主体、来源、日期、作者、具体许可及原图身份；门禁锁定 `sourceSha1`，换图不能仅凭同一入口 ID 自动继承审核。完整原始 metadata、下载尺寸、字节数和本地 SHA-256 保留在 `source-records.json`。

已纠正同名误图、同照片裁剪重复、平安餐点、红场演出人物、豫园外围茶楼、香港历史地图、台北藏品扫描以及浅草寺器物图。豫园采用园内池石亭廊和古戏台；官方园方来源核对内园关系。照片拍摄、上传、建筑建成、历史事件日期分别说明，不把后期建筑照片冒充历史事件现场。

南山塔当前两图是城市／南山远景及从塔方向观察城市，不是塔楼本体近景；没有声称取得建筑或夜间灯光的全面授权。埃菲尔及卢浮宫选白昼旧建筑视图，不使用受保护的夜间照明或 Pei 金字塔主图。Merlion 商标／推广限制、罗马素材 `ita-mibac` 提示、NASA 合作方权利等另存来源文档，正式公开或商业用途前需用户人工确认。

58 地标目前是简洁原创的建筑、文化、自然和科学观察内容，不表示每个点都已写成完整详细历史故事或具备历史事件现场照片。新增事件需要补独立来源和对应图片关系，不自动编故事凑完成率。

## 可复现操作

1. 打开本地预览，选择无摄像头／鼠标模式，点击地球。
2. 拖动旋转、滚轮或工具按钮缩放；使用暂停／开启按钮检查自转。
3. 选择亚洲 → 中国组 → 北京，再选天安门、故宫、八达岭、鸟巢或天坛；选择只聚焦，点击球面标签才开玻璃图文。
4. 切下一张、上一张和缩略图，关闭面板，观察原缩放与朝向未重置。
5. 返回全城市标注，再选欧洲 → 法国 → 巴黎，重复其他城市与其地标。
6. 返回太阳系，选火星或土星，选择其经典区域并点击注解；两者使用同一面板与图库，不走国家／城市层级。
7. `?tv=1` 可检查键盘 D-pad 模拟；不是 Fire TV 实机认证。
