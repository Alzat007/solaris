# SOLARIS · 掌中星系

一个可本地运行、用手势探索的太阳系。React 19 + TypeScript + Vite + Three.js / React Three Fiber，使用 GPU 粒子、GLSL 太阳、GSAP 镜头过渡和 MediaPipe Hand Landmarker。

公开测试版网站：[SOLARIS · 掌中星系](https://alzat007.github.io/solaris/)。使用 GitHub Pages 公开托管，无需登录。具体更新状态以部署任务完成及在线页面为准，不以本地构建成功推断已经发布。

这是公开测试版，不是已经完成人工编辑审核的正式内容版本，也不表示 Amazon Appstore 上架、Fire TV APK 验证或比赛作品正式提交。新旧内容均仍保留 `humanReview: "pending"`；页面持续显示测试版标识，信息卡保留人工复核提示、来源与署名。2026-10-05 用户授权更新既有 GitHub Pages；本版发布范围包含同页地球探索，实际上线状态仍以部署任务和在线页面为准。

## 当前方向：最终任务书的连续星球探索

2026-10-05 最终任务书继续以自由旋转和连续接近作为主体验；大洲、国家、城市目录仅作辅助导航。最终仍覆盖八大行星与全球首都及精选名城，不缩为北京故事馆。现有太阳系及下述历史原型保留，不把云幕切换、示意建筑或影像平面视为真实地理探索验收通过。

主站在太阳系点击地球后，完成原有靠近动画便自动进入同页地球探索，不再提供“连续地球预览”按钮或跳转另一页。复用现有 Cesium 探索模块，交接实际地球姿态、相机位置/方向与有效 FOV，不重置为北京默认整球；旧 R3F 场景保持挂载但暂停渲染，只有一个可见且活跃的地球视图。摄像头输入更换接收者，不停止/重建既有检测会话。返回恢复太阳系，取消返回保留最近地理相机姿态。`globe-lab.html` 只保留为独立工程测试入口。

默认仍在 WGS84 椭球上使用本地全球低分辨率影像，支持双轴抓取、指向缩放、北京飞行、接管、取消与跳过。北京三个既有地点已接到地理投影热点与点击式玻璃图文，关闭保留相机/热点焦点。最低观察高度仍为 250 km，**不是城市清晰影像、真实地形或建筑交付**。同页交接已接通不等于两套渲染器的光照、星空和大气外观完全一致，也不等于真实数据接通。

真实数据入口使用 World Terrain (1) + Google Satellite with Labels (3830183)，不是另建 Google 直连。只有用户自行准备受限 `assets:read` 客户端令牌，在忽略的 `.env.local` 中配置 `VITE_CESIUM_ION_READ_TOKEN`，重启开发服务器并主动打开 `/?data=ion` 后选择地球（或独立工程入口 `/globe-lab.html?data=ion`）才会请求。默认与 `?qa=1` 不调用真实服务；无凭据、超时或失败不会悄悄替换底图并声称连接成功。客户端令牌可见，忽略文件不是保密措施。**当前没有配置令牌或通过真实数据验证。** 资源、权限、费用和完整缺口见 [开发与验证记录](docs/GLOBE_LAB_V5.md)。

新增 CesiumJS 1.146.0 和 Lucide 图标，没有升级其他已有依赖；当前构建需 Node.js 22.12+。`predev` / `prebuild` 将 Cesium 静态资源及完整许可证复制到本地。公开构建不配置地图令牌，默认不调用付费地理数据服务；独立实验入口仅用于工程验证，不是额外的产品入口。

## 已保留原型：分层沉浸式探索

在 [V3 原文副本](docs/PRODUCT_SCOPE_V3.md) 的全行星、首都及名城范围上，历史分层方案为：太阳系 → 行星总览 → 区域选择 → 镜头接近／进入 → 局部 3D 视图 → 热点 → 磨砂玻璃信息卡。地球细分为大洲 → 国家 → 城市。它作为已有原型保留，不是 V5 连续地理探索已完成的证据。不能从列表直接跳图文读物，也不能把样板当成最终范围。不新增 AI 聊天、手机 App、账号或强制答题。实现与验证边界见 [原型交付记录](docs/IMMERSIVE_EXPLORATION.md)。

### 第一阶段验收

HUD 底部的 SOLARIS Talk 输入接受八大行星中文或英文名称、`带我去火星`、`前往土星`、`go to Mars`、`show me Saturn`，以及 `返回太阳系` / `back to solar system`。点击输入框右侧按钮或按 Enter 执行；中文输入法选字的 Enter 不应执行指令。

- 使用原有 `interaction.select` / `interaction.return`，不直接改写选中对象来伪造场景动作。
- 控制器接受操作时先显示正在前往，真实场景过渡完成后才显示抵达。动画中收到另一条指令会报告忙碌，不排队、不抢占已有动作。
- 已经稳定聚焦同一行星时提示当前已在该行星，不重播动画或重置缩放。
- 空输入、未知天体、否定句、多目标或问答句不产生动作。太阳内部、坍缩和正在缩放等状态给出明确限制。
- 保留原有手势、鼠标、键盘、触屏控制。此阶段不发送文字或摄像头画面到外部服务。

实际运行结果与仍待真人验证的项目记录在 `QA.md` 的最新章节，不能用原版测试记录替代新增功能验证。

## 手势操作：指向、张开拇指、拖动、拨动、握拳、✌ 旋腕

等待开场结束，点击 **开启手势控制** 并允许摄像头访问。让手完整出现在镜头内，保持光线充足。开启后显示带骨架的小型**本机镜像预览**，重点高亮拇指骨链与食指尖；识别为 ✌ 时突出食指和中指。可手动收起，查看资料和帮助时自动收起。首次入镜或重新追踪后的前 **250ms** 只跟踪光标，随后显示就绪。

| 动作                                                    | 作用                                                                                                     |
| ------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| **指**：收拢大拇指，伸出食指，其余手指自然半弯          | 移动光标、瞄准天体或 HUD；同一目标稳定约 250ms 后圆环填满。移动或只指向不会选择。                        |
| **张开大拇指**：目标锁定后，保持食指指向并张开拇指      | 选择原锁定目标。所有行星、太阳与可用 HUD 共用「收拢拇指并指向 → 锁定 → 张开拇指确认」。                  |
| **拖**：在空白处或已聚焦的当前星球上捏住并移动          | 总览中旋转太阳系，行星总览中旋转当前星球；不触发选择，松开后有短暂惯性。                                 |
| **拨**：张掌向左／向右快速拨动                          | 仅在行星聚焦后切换下一颗／上一颗行星。                                                                   |
| **握**：握拳保持约 600ms                                | 返回进度环填满后返回太阳系；从太阳内部退出到太阳外部。中途松开即取消。                                   |
| **✌ 旋腕**：食指、中指伸出，其余两指收起，拇指自然放置 | 保持约 250ms，出现旋钮后像拧旋钮一样转动手腕：镜像预览中顺时针向右放大，逆时针向左缩小。左右手方向一致。 |

**食指保持指向，张开大拇指确认。** 先把大拇指收向掌边，稳定指向同一个目标约 **250ms**；看到圆环填满和「张开大拇指进入」后张开拇指，可靠保持至少 **80ms** 才确认一次。开始时拇指已经张开会提示先收回。不要弯曲食指，弯指和双指捏合都不会进入。

选择读取掌内拇指横向展开量：沿小指根到食指根的方向，将拇指尖相对食指根的位置投影并除以掌宽。收拢门槛为 **0.25 及以下**；张开须达到 **0.55 及以上**，同时拇指伸展率至少 **0.65**。食指关节角度和角速度不参与选择触发。左右手、镜像与正常转腕使用同一归一化量。

锁定后，即使光标轻微离开星球，也仍选择原目标。收拢拇指并稳定指着同一目标可以继续等待；偏离目标、快速移动或开始张开拇指后保留最多 **450ms**，换目标或重新指回不会续期。确认后必须把大拇指收回到 **0.25 及以下并保持 100ms**，才能进行下一次选择；一直张开不会重复进入。

**双指捏合不选择天体或 HUD。** 总览空白处捏住并移动，即使经过星球也不会变成选择；行星总览中可捏住当前星球旋转，其他星球或 HUD 上开始捏合仍消费到释放。所有场景动画期间锁定选择／旋转／缩放；地点下降期间额外允许一只新就绪的手握拳 600ms 取消，必须释放后才能再次返回，沿用已有安全门槛。动画中可以收回大拇指释放，但不会累计下一次目标锁定。太阳内部与坍缩完成后，只能指向并张开拇指确认当前可用 HUD，不能再选择天体；太阳内部仍可握拳返回。

**缩放由 ✌ 旋腕控制。** 保持确认结束时记录当前手腕角度，±10° 内不改变大小；转得越多，缩放越快，40° 时达到最高速度，每秒最多改变 0.65 倍，范围为原始大小的 **0.35–1.75 倍**。把手移到别处不会缩放。转回起始角附近立即停速；收起 ✌ 或识别暂时不确定，也立即停止改变目标大小。短暂漏检最多保留 **150ms** 的基准，及时恢复无需重新校准，超过后退出；再次比 ✌ 需重新保持确认。停速时将目标与当前画面的比例差限制在 0.01 内，再由原有平滑阻尼完成收尾。

目标已经锁定或正在张开拇指确认时，不会转入 ✌ 缩放、拖动、拨动或握拳返回。尚未锁定目标时，✌ 从候选确认、就绪、旋转到短暂漏检期间独占输入，不会同时选择、拖动、拨动、握拳返回或触发双掌彩蛋。缩放可用于太阳系总览和行星聚焦；太阳飞入阶段全程动画锁定，太阳内部不启用。原五指聚拢开合、双手捏合缩放已退出正式操作。

进入行星后，镜头动画结束 **400ms** 后自动淡入资料卡。三指不再控制资料；✌ 不再返回，返回统一使用握拳。双手快速张开不再进入太阳，太阳与行星使用相同的选择动作。

帮助面板还说明双掌彩蛋：

- **宇宙坍缩**：在太阳系总览中双掌张开，共同向中心靠近约 1 秒，看到「保持片刻」后停留约 200ms。无需双掌碰到一起：掌间距降到初始约 62% 或归一化间距 0.32 的允许范围，并满足双手内移行程即可。界面显示手数、阶段和百分比。
- **完整坍缩／重生**：确认后播放 2.4 秒坍缩，四周星光、星尘和轨道向中心汇聚，留下螺旋吸积盘、流入粒子和脉动能量核。动画结束后，双掌从中心向两侧拉开，触发 Big Bang 与粒子爆发。底部 **「坍缩」／「重生」** 按钮和空格键可以直接体验同一效果。此动作不进入太阳。

识别把「有效跟踪」和「姿势证据」分开：左右手标签暂时低分、手指自然弯曲或短暂姿势不确定，不会直接清除整只手的身份。双掌弱姿势最多暂停 220ms，期间不累计确认时间；✌ 旋腕已就绪后的弱帧按独立的 150ms 宽限处理。姿势判断结合指链伸展率、指尖离腕距离和掌内 3D 对向位移。手腕旋转只取食指根至小指根的掌部轴线，不取容易晃动的指尖；掌部接近侧面或投影过短时暂停旋钮。

光标反馈依次表达「检测到手 → 命中目标 → 动作确认中 → 已触发」：蓝色轻光圈、目标细环、锁定填充、拇指张开确认时圆环收缩／握拳进度环和触发脉冲。✌ 候选出现保持进度，确认后显示随掌心移动的旋钮、方向提示与当前百分比。底部同时显示识别姿势和动作状态。

第一次检测到手后，选择教程依次提示 **「收拢拇指，食指指向星球」→「张开大拇指进入」**；成功完成一次拇指张开选择后保存 `solarisThumbOpenTutorialCompleted=true` 并隐藏。仅悬停、锁定或用鼠标点击不会完成这条教程。首次使用旋钮时另显示 **「↶ ✌ ↷ · 旋转手腕缩放」**；实际旋转改变大小后保存独立的 `solarisVZoomTutorialCompleted=true`。右下角 `?` 可随时打开帮助。

**鼠标与键盘：**移动瞄准，点击天体选择，总览拖动旋转太阳系、行星总览拖动旋转当前星球，滚轮缩放；行星聚焦后 `← / →` 切换，`Esc` 分层返回或取消行星／地点转场，`Space` 坍缩／重生，`S` 进入太阳，`I` 手动切换资料卡。**触屏：**保留原点按、总览单指旋转、双指缩放和聚焦左右拨动；没有新增手机 App。默认静音，主动开启声音后才创建音频上下文。

打开 [手势调试模式](https://alzat007.github.io/solaris/?debugGesture=true)，或在本地地址后加 `?debugGesture=true`，查看镜像骨架、姿势与跟踪证据、拇指展开量／伸展率／几何有效性、指向证据、悬停与锁定目标、锁定／张开／收回状态，以及只用于诊断的食指角度／角速度、旋钮状态、起始／当前掌部角度、角度差、缩放方向和速度、死区、V 姿势分数、缩放比例、双掌阶段、场景锁与渲染 FPS。`trackingConfidence` 仅表示关键点几何有效性，不是 MediaPipe 未提供的真实跟踪分数，也不是识别准确率。正式访问默认隐藏调试信息。再次点击摄像头按钮即停止追踪并释放资源。

开发服务器的 `/tests/gesture-lab.html` 提供合成 21 关键点回放，不使用摄像头，也不包含在生产构建中。自动化回归检查拇指掌内展开量、自然指向、收拢后稳定锁定、张开离靶仍选原目标、单次触发与明确收回，以及 ✌ 的镜像旋转方向、角度跨越 ±π、静止微抖、平移、短暂漏检与输入互斥；旧五指几何样本保留作反例和诊断。合成样本不能替代真人摄像头与设备验证。

完整的文件职责、状态机、阈值、优先级与调参说明见 [GESTURE_SYSTEM_V2.md](GESTURE_SYSTEM_V2.md)。前期现成方案的源码、许可与适用范围核查见 [GESTURE_RESEARCH.md](GESTURE_RESEARCH.md)；识别继续使用现有 MediaPipe 关键点与本项目几何计算。

### 有摄像头画面，但检测不到手

画面显示成功只表示摄像头可用，手部模型仍需单独加载。网站现在分别显示摄像头连接、模型加载、识别运行与画面冻结；检测不到手持续 5 秒后可点击 **切换兼容识别**。兼容模式复用当前摄像头，使用 CPU 推理，并把检测、手部存在和跟踪门槛设为 [MediaPipe 官方默认的 0.5](https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker/web_js)。正常模式仍使用 0.65；动作确认与手势几何判据不变。

也可打开 [兼容识别入口](https://alzat007.github.io/solaris/?handTracking=cpu)，再主动点击开启手势。这个入口不会自动开启摄像头。GPU 初始化或推理抛错会自动尝试一次 CPU，单纯没有手部检出不会被认定为显卡故障。兼容模式是排查途径，不代表已确定 Windows / Edge 故障；光照、手的大小与模型加载也需要分开观察。

`/tests/camera-lab.html` 在开发环境用 canvas 视频流替代摄像头，实跑原版检测模型和兼容切换按钮。可将 [MediaPipe 官方测试图](https://github.com/google-ai-edge/mediapipe/blob/master/mediapipe/tasks/testdata/vision/BUILD) `right_hands.jpg`、`victory.jpg`、`pointing_up.jpg`、`fist.jpg` 从 `https://storage.googleapis.com/mediapipe-assets/` 下载到忽略的 `artifacts/` 目录，检查实际模型检测。V 样图支持镜像、左右旋转 30° 和归零；这只变换输入照片像素，不替换模型输出关键点。测试页面和图片均不进入生产发布，不申请真实摄像头权限。

## 项目结构

- `src/scene`：太阳系组合、深空、轨道、屏幕与 3D 交互场映射。
- `src/planets`：Sun、八个独立行星组件、PlanetBase、表面材质、日珥、地球云层和月球、土星粒子环。
- `src/particles`：ParticleEngine 共享物理参数、GPU 粒子、组装与爆发 Shader、Big Bang 实例化光迹，以及坍缩螺旋光迹、吸积盘和能量核心。
- `src/gesture`：摄像头生命周期、稳定手身份、21 点特征提取、目标锁定／拇指张开选择、空白 Pinch 拖动、✌ 旋腕缩放与旋钮反馈、互斥动作路由、光标、镜像预览、教程与 Debug。模型推理限制为 20Hz，光标由渲染循环继续插值。
- `src/interaction`：显式状态机、互斥动画时间线、轻量外部 UI 状态。
- `src/camera`：相机惯性、位置和四元数插值、冲击后坐。
- `src/audio`：本地合成的低频氛围、切换和爆发声。
- `src/performance`：平均帧率监测、持续低帧率降级。
- `src/ui`：最小 HUD、行星资料、手势提示和调试画面。
- `src/data/planets.ts`：真实数据与视觉半径、轨道尺寸分离。

## 性能与范围

HIGH 静态分配约 27 万主粒子，其中太阳 9.5 万、星尘 11.5 万、土星环 6 万；Big Bang 另有最多 1.8 万 GPU 实例化光迹。坍缩特效独立使用最多 1.2 万 GPU 实例化光迹与两张 Shader 平面，MEDIUM／LOW 分别显示 6,500／2,400 条。MEDIUM 使用一半主粒子，LOW 使用约 5.4 万。连续平均帧率低于阈值时依次降低 drawRange、DPR 与 Bloom，避免逐帧重写粒子。DPR 上限 1.5。粒子运动使用解析 Shader 物理场，属于可实时响应的艺术模拟，不是 N 体天体力学。

地球使用本地日照/夜景贴图，其他星球为程序化 Shader。星球尺寸、距离和时间流速均为艺术比例。气态行星的卫星发现数量持续变化，资料 HUD 使用“多颗”或“至少”标记。

双手动作的识别依赖光照、手掌可见程度及检测稳定性。真实手势准确率及 iPhone Safari / Android Chrome 的实际设备帧率需要在对应设备上验证。
