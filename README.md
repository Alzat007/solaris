# SOLARIS · 掌中星系

一个可本地运行、用手势探索的太阳系。React 19 + TypeScript + Vite + Three.js / React Three Fiber，使用 GPU 粒子、GLSL 太阳、GSAP 镜头过渡和 MediaPipe Hand Landmarker。

正式网站：[SOLARIS · 掌中星系](https://alzat007.github.io/solaris/)。使用 GitHub Pages 公开托管，无需登录。后续部署以 GitHub Pages 为准。

## 发布更新

推送 `main` 分支后，`.github/workflows/pages.yml` 自动安装依赖、运行测试、构建和校验资源，再发布到 GitHub Pages。MediaPipe 模型、WASM 和地球纹理一同发布，摄像头仅在用户主动开启后使用。

本地复核 GitHub Pages 的仓库子路径：

```sh
VITE_BASE_PATH=/solaris/ npm run build
VITE_BASE_PATH=/solaris/ node scripts/verify-static-export.mjs
npm run preview
```

打开预览地址下的 `/solaris/`。普通本地开发仍用 `npm run dev`，默认根路径 `/`。

## 运行

需要 **Node.js 20.19+ 或 22.12+**。

```sh
npm install
npm run dev
```

打开终端显示的地址，默认 `http://localhost:5173`。摄像头只能用于 **localhost 或 HTTPS**；通过局域网 HTTP 在手机上打开时，使用触屏模式。当前 Mac 也可以双击 `启动 SOLARIS.command` 使用已有的 Codex Node 运行时。

```sh
npm run build       # TypeScript 校验和生产构建
npm run preview     # 预览 dist
npm test            # 识别几何、手势状态机、动作路由与输入约束
npm run format      # 格式化源代码
```

## 手势操作：指向、轻扣食指、拖动、拨动、握拳、✌ 旋腕

等待开场结束，点击 **开启手势控制** 并允许摄像头访问。让手完整出现在镜头内，保持光线充足。开启后显示带骨架的小型**本机镜像预览**，识别为 ✌ 时重点高亮食指和中指；可手动收起，查看资料和帮助时自动收起。首次入镜或重新追踪后的前 **250ms** 只跟踪光标，随后显示就绪。

| 动作                                                    | 作用                                                                                                     |
| ------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| **指**：伸出食指，其他手指自然弯曲                      | 移动光标、瞄准天体或 HUD；命中后出现光环和名称。移动本身不触发导航。                                     |
| **轻扣食指**：稳定指向约 250ms，圆环填满后轻轻弯曲食指  | 选择锁定目标。所有行星、太阳与可用 HUD 都用「指向 → 等待锁定 → 轻弯食指确认」。                          |
| **拖**：在空白处捏住并移动                              | 在太阳系总览中旋转太阳系；松开后有短暂惯性并缓慢停下。                                                   |
| **拨**：张掌向左／向右快速拨动                          | 仅在行星聚焦后切换下一颗／上一颗行星。                                                                   |
| **握**：握拳保持约 600ms                                | 返回进度环填满后返回太阳系；从太阳内部退出到太阳外部。中途松开即取消。                                   |
| **✌ 旋腕**：食指、中指伸出，其余两指收起，拇指自然放置 | 保持约 250ms，出现旋钮后像拧旋钮一样转动手腕：镜像预览中顺时针向右放大，逆时针向左缩小。左右手方向一致。 |

**选择像“瞄准后扣一下扳机”。** 食指伸直，其他手指自然半弯、拇指自然放置。稳定指向同一个目标约 **250ms**，看到圆环填满和「轻弯食指进入」后再扣动食指。系统读取食指中间关节的角度：从伸直弯到 **115° 以下**，并检测到明显下降趋势，才确认一次；不用把整只手握紧。快速扫过目标、只指着不弯曲、缓慢放松都不会进入。

锁定后，指尖因弯曲离开星球也仍选择原目标。稳定指着同一目标可以继续等待；偏离目标、快速移动或开始弯指后保留最多 **450ms**，期间换目标不会重新续期。确认后必须把食指伸回 **145° 以上并保持 100ms**，才能进行下一次选择；一直弯着不会重复进入，也不会接着触发握拳返回。左右手都支持。

**双指捏合只保留总览空白处的拖动旋转，不再选择天体或 HUD。** 空白处捏住并移动，即使经过星球也不会变成选择；在目标上开始捏合也不会进入。所有场景动画期间锁定手势；动画中可以伸直释放食指，但不会累计下一次目标锁定。太阳内部与坍缩完成后，只能用食指确认当前可用 HUD，不能再选择天体；太阳内部仍可握拳返回。

**缩放由 ✌ 旋腕控制。** 保持确认结束时记录当前手腕角度，±10° 内不改变大小；转得越多，缩放越快，40° 时达到最高速度，每秒最多改变 0.65 倍，范围为原始大小的 **0.35–1.75 倍**。把手移到别处不会缩放。转回起始角附近立即停速；收起 ✌ 或识别暂时不确定，也立即停止改变目标大小。短暂漏检最多保留 **150ms** 的基准，及时恢复无需重新校准，超过后退出；再次比 ✌ 需重新保持确认。停速时将目标与当前画面的比例差限制在 0.01 内，再由原有平滑阻尼完成收尾。

食指目标已经锁定或正在轻扣时，不会转入 ✌ 缩放、拖动、拨动或握拳返回。尚未锁定目标时，✌ 从候选确认、就绪、旋转到短暂漏检期间独占输入，不会同时选择、拖动、拨动、握拳返回或触发双掌彩蛋。缩放可用于太阳系总览和行星聚焦；太阳飞入阶段全程动画锁定，太阳内部不启用。原五指聚拢开合、双手捏合缩放已退出正式操作。

进入行星后，镜头动画结束 **400ms** 后自动淡入资料卡。三指不再控制资料；✌ 不再返回，返回统一使用握拳。双手快速张开不再进入太阳，太阳与行星使用相同的选择动作。

帮助面板还说明双掌彩蛋：

- **宇宙坍缩**：在太阳系总览中双掌张开，共同向中心靠近约 1 秒，看到「保持片刻」后停留约 200ms。无需双掌碰到一起：掌间距降到初始约 62% 或归一化间距 0.32 的允许范围，并满足双手内移行程即可。界面显示手数、阶段和百分比。
- **完整坍缩／重生**：确认后播放 2.4 秒坍缩，四周星光、星尘和轨道向中心汇聚，留下螺旋吸积盘、流入粒子和脉动能量核。动画结束后，双掌从中心向两侧拉开，触发 Big Bang 与粒子爆发。底部 **「坍缩」／「重生」** 按钮和空格键可以直接体验同一效果。此动作不进入太阳。

识别把「有效跟踪」和「姿势证据」分开：左右手标签暂时低分、手指自然弯曲或短暂姿势不确定，不会直接清除整只手的身份。双掌弱姿势最多暂停 220ms，期间不累计确认时间；✌ 旋腕已就绪后的弱帧按独立的 150ms 宽限处理。姿势判断结合指链伸展率、指尖离腕距离和掌内 3D 对向位移。手腕旋转只取食指根至小指根的掌部轴线，不取容易晃动的指尖；掌部接近侧面或投影过短时暂停旋钮。

光标反馈依次表达「检测到手 → 命中目标 → 动作确认中 → 已触发」：蓝色轻光圈、目标细环、锁定填充、轻扣时圆环收缩／握拳进度环和触发脉冲。✌ 候选出现保持进度，确认后显示随掌心移动的旋钮、方向提示与当前百分比。底部同时显示识别姿势和动作状态。

第一次检测到手后，选择教程依次提示 **「指向星球」→「轻弯食指进入」**；成功完成一次食指选择后保存 `solarisIndexTriggerTutorialCompleted=true` 并隐藏。仅悬停、锁定或用鼠标点击不会完成这条教程。首次使用旋钮时另显示 **「↶ ✌ ↷ · 旋转手腕缩放」**；实际旋转改变大小后保存独立的 `solarisVZoomTutorialCompleted=true`。右下角 `?` 可随时打开帮助。

**鼠标与键盘：**移动瞄准，点击天体选择，在总览中拖动旋转，滚轮缩放；行星聚焦后 `← / →` 切换，`Esc` 返回，`Space` 坍缩／重生，`S` 进入太阳，`I` 手动切换资料卡。**触屏：**点按天体选择，总览单指拖动旋转，双指缩放，行星聚焦后左右拨动切换。默认静音，主动开启声音后才创建音频上下文。

打开 [手势调试模式](https://alzat007.github.io/solaris/?debugGesture=true)，或在本地地址后加 `?debugGesture=true`，查看镜像骨架、姿势与跟踪证据、食指关节角度／角速度、指向证据、悬停与锁定目标、锁定／按压／释放状态、旋钮状态、起始／当前掌部角度、角度差、缩放方向和速度、死区、V 姿势分数、缩放比例、双掌阶段、场景锁与渲染 FPS。`trackingConfidence` 仅表示关键点几何有效性，不是 MediaPipe 未提供的真实跟踪分数，也不是识别准确率。正式访问默认隐藏调试信息。再次点击摄像头按钮即停止追踪并释放资源。

开发服务器的 `/tests/gesture-lab.html` 提供合成 21 关键点回放，不使用摄像头，也不包含在生产构建中。自动化回归检查食指 PIP 角度、自然指向、稳定锁定、弯曲离靶、单次触发与明确释放，以及 ✌ 的镜像旋转方向、角度跨越 ±π、静止微抖、平移、短暂漏检与输入互斥；旧五指几何样本保留作反例和诊断。合成样本不能替代真人摄像头与设备验证。

完整的文件职责、状态机、阈值、优先级与调参说明见 [GESTURE_SYSTEM_V2.md](GESTURE_SYSTEM_V2.md)。前期现成方案的源码、许可与适用范围核查见 [GESTURE_RESEARCH.md](GESTURE_RESEARCH.md)；识别继续使用现有 MediaPipe 关键点与本项目几何计算。

### 有摄像头画面，但检测不到手

画面显示成功只表示摄像头可用，手部模型仍需单独加载。网站现在分别显示摄像头连接、模型加载、识别运行与画面冻结；检测不到手持续 5 秒后可点击 **切换兼容识别**。兼容模式复用当前摄像头，使用 CPU 推理，并把检测、手部存在和跟踪门槛设为 [MediaPipe 官方默认的 0.5](https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker/web_js)。正常模式仍使用 0.65；动作确认与手势几何判据不变。

也可打开 [兼容识别入口](https://alzat007.github.io/solaris/?handTracking=cpu)，再主动点击开启手势。这个入口不会自动开启摄像头。GPU 初始化或推理抛错会自动尝试一次 CPU，单纯没有手部检出不会被认定为显卡故障。兼容模式是排查途径，不代表已确定 Windows / Edge 故障；光照、手的大小与模型加载也需要分开观察。

`/tests/camera-lab.html` 在开发环境用 canvas 视频流替代摄像头，实跑原版检测模型和兼容切换按钮。可将 [MediaPipe 官方测试图](https://github.com/google-ai-edge/mediapipe/blob/master/mediapipe/tasks/testdata/vision/BUILD) `right_hands.jpg`、`victory.jpg` 从 `https://storage.googleapis.com/mediapipe-assets/` 下载到忽略的 `artifacts/` 目录，检查实际模型检测。V 样图支持镜像、左右旋转 30° 和归零；这只变换输入照片像素，不替换模型输出关键点。测试页面和图片均不进入生产发布，不申请真实摄像头权限。

## 项目结构

- `src/scene`：太阳系组合、深空、轨道、屏幕与 3D 交互场映射。
- `src/planets`：Sun、八个独立行星组件、PlanetBase、表面材质、日珥、地球云层和月球、土星粒子环。
- `src/particles`：ParticleEngine 共享物理参数、GPU 粒子、组装与爆发 Shader、Big Bang 实例化光迹，以及坍缩螺旋光迹、吸积盘和能量核心。
- `src/gesture`：摄像头生命周期、稳定手身份、21 点特征提取、食指锁定／轻扣选择、空白 Pinch 拖动、✌ 旋腕缩放与旋钮反馈、互斥动作路由、光标、镜像预览、教程与 Debug。模型推理限制为 20Hz，光标由渲染循环继续插值。
- `src/interaction`：显式状态机、互斥动画时间线、轻量外部 UI 状态。
- `src/camera`：相机惯性、位置和四元数插值、冲击后坐。
- `src/audio`：本地合成的低频氛围、切换和爆发声。
- `src/performance`：平均帧率监测、持续低帧率降级。
- `src/ui`：最小 HUD、行星资料、手势提示和调试画面。
- `src/data/planets.ts`：真实数据与视觉半径、轨道尺寸分离。

## 性能与范围

HIGH 静态分配约 27 万主粒子，其中太阳 9.5 万、星尘 11.5 万、土星环 6 万；Big Bang 另有最多 1.8 万 GPU 实例化光迹。坍缩特效独立使用最多 1.2 万 GPU 实例化光迹与两张 Shader 平面，MEDIUM／LOW 分别显示 6,500／2,400 条。MEDIUM 使用一半主粒子，LOW 使用约 5.4 万。连续平均帧率低于阈值时依次降低 drawRange、DPR 与 Bloom，避免逐帧重写粒子。DPR 上限 1.5。粒子运动使用解析 Shader 物理场，属于可实时响应的艺术模拟，不是 N 体天体力学。

地球使用本地日照/夜景贴图，其他星球为程序化 Shader。星球尺寸、距离和时间流速均为艺术比例。气态行星的卫星发现数量持续变化，资料 HUD 使用“多颗”或“至少”标记。

双手动作的识别依赖光照、手掌可见程度及检测稳定性。真实手势准确率及 iPhone Safari / Android Chrome 的实际设备帧率需要在对应设备上验证。

## 隐私与资源

视频仅在浏览器内处理，不录像、不持久保存、不上传。MediaPipe 模型和 WASM 均从本站加载；首次安装后无需依赖模型 CDN。`postinstall` 会把与依赖版本一致的 WASM 复制到 `public/mediapipe`。字体通过 Google Fonts 请求；无法联网时自动使用系统字体。

- MediaPipe Hand Landmarker：Google 官方 float16 模型，`public/models/hand_landmarker.task`。
- Earth day / night：Three.js r160 examples 的 `earth_atmos_2048.jpg` 和 `earth_lights_2048.png`，来源 https://github.com/mrdoob/three.js/tree/r160/examples/textures/planets 。
- 原始素材与第三方许可证信息见 `THIRD_PARTY_NOTICES.md`。

WebGL 上下文丢失、渲染初始化/Shader 故障会显示可恢复提示；摄像头拒绝、缺失或模型失败会进入鼠标模式，不阻断作品。
