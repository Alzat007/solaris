# SOLARIS · 掌中星系

一个可本地运行、用双手拨动的太阳系。React 19 + TypeScript + Vite + Three.js / React Three Fiber，使用 GPU 粒子、GLSL 太阳、GSAP 镜头过渡和 MediaPipe Hand Landmarker。

正式网站：[SOLARIS · 掌中星系](https://alzat007.github.io/solaris/)。使用 GitHub Pages 公开托管，无需登录。后续部署以 GitHub Pages 为准。

## 发布更新

推送 `main` 分支后，`.github/workflows/pages.yml` 自动安装依赖、运行测试、构建和校验资源，再发布到 GitHub Pages。MediaPipe 模型、WASM 和地球纹理一同发布，摄像头仅在用户主动开启后使用。

本地复核 GitHub Pages 的仓库子路径：

```sh
VITE_BASE_PATH=/solaris/ npm run build
VITE_BASE_PATH=/solaris/ node scripts/verify-static-export.mjs
npm run preview
```

打开预览地址下的 `/solaris/`。普通本地开发仍用 `npm run dev`，默认根路径 `/`。

## 运行

需要 **Node.js 20.19+ 或 22.12+**。

```sh
npm install
npm run dev
```

打开终端显示的地址，默认 `http://localhost:5173`。摄像头只能用于 **localhost 或 HTTPS**；通过局域网 HTTP 在手机上打开时，使用触屏模式。当前 Mac 也可以双击 `启动 SOLARIS.command` 使用已有的 Codex Node 运行时。

```sh
npm run build       # TypeScript 校验和生产构建
npm run preview     # 预览 dist
npm test            # 识别几何、手势状态机、动作路由与输入约束
npm run format      # 格式化源代码
```

## Gesture System V2.1：指、捏、拖、拨、握

等待开场结束，点击 **开启手势控制** 并允许摄像头访问。让手完整出现在镜头内，保持光线充足。开启后显示带骨架的小型**本机镜像预览**，拇指和食指尖单独高亮；可手动收起，查看资料和帮助时自动收起。手重新出现后的前 **250ms** 只跟踪光标，随后显示就绪。

| 动作                               | 作用                                                                   |
| ---------------------------------- | ---------------------------------------------------------------------- |
| **指**：伸出食指，其他手指自然弯曲 | 移动光标、瞄准天体或 HUD；命中后出现光环和名称。移动本身不触发导航。   |
| **捏**：拇指和食指捏合约 140ms     | 选择当前目标。所有行星与太阳都用「指向 → 捏合 → 进入」。               |
| **拖**：在空白处捏住并移动         | 在太阳系总览中旋转太阳系；松开后有短暂惯性并缓慢停下。                 |
| **拨**：张掌向左／向右快速拨动     | 仅在行星聚焦后切换下一颗／上一颗行星。                                 |
| **握**：握拳保持约 600ms           | 返回进度环填满后返回太阳系；从太阳内部退出到太阳外部。中途松开即取消。 |

捏合开始后目标即被捕获；一次捏合只能确认一次，松开后才能再次确认。空白处开始的捏合属于拖动，即使经过星球也不会变成选择。所有场景动画期间锁定手势。场景解锁后也可以指向并捏合当前可用的 HUD 按钮，包括太阳内部与坍缩完成后的状态。

进入行星后，镜头动画结束 **400ms** 后自动淡入资料卡。**已移除三指资料、✌ 返回，以及双手快速张开进入太阳。** 太阳现在与行星使用相同的选择动作。

双手玩法在帮助面板中单独展开：

- **双手捏合缩放**：两只手都完成捏合确认后，拉开使世界变大，靠近使世界变小；任意一手松开即结束。双掌距离本身不控制缩放。
- **宇宙彩蛋**：在太阳系总览中双掌张开，共同向中心靠近约 1 秒，看到「保持片刻」后停留约 200ms。无需双掌碰到一起：掌间距降到初始约 62% 或归一化间距 0.32 的允许范围，并满足双手内移行程即可。界面显示手数、阶段和百分比。
- **完整坍缩／重生**：确认后播放 2.4 秒坍缩，四周星光、星尘和轨道向中心汇聚，留下螺旋吸积盘、流入粒子和脉动能量核。动画结束后，双掌从中心向两侧拉开，触发 Big Bang 与粒子爆发。底部 **「坍缩」／「重生」** 按钮和空格键可以直接体验同一效果。此动作不进入太阳。

V2.1 把「有效跟踪」和「姿势证据」分开：左右手标签暂时低分、手指自然弯曲或短暂姿势不确定，不再直接清除整只手的身份。双掌弱姿势最多暂停 220ms，期间不累计确认时间；实际丢手或无效关键点仍解除正在执行的操作。姿势判断结合指链伸展率、指尖离腕距离和掌内 3D 对向位移，兼顾内置摄像头噪声、侧转与紧凑捏合。

光标反馈依次表达「检测到手 → 命中目标 → 动作确认中 → 已触发」：蓝色轻光圈、目标高亮、捏合收缩／握拳进度环和触发脉冲。识别连接状态与动作确认分开显示。

第一次检测到手后，教程每次只显示一个步骤：**指向 → 捏合进入 → 左右拨动 → 握拳返回**。成功返回后保存 `solarisGestureTutorialCompleted=true`，后续不再重复。若第一次进入的是太阳内部，教程直接提示握拳返回。右下角 `?` 可随时打开帮助。

**鼠标与键盘：**移动瞄准，点击天体选择，在总览中拖动旋转，滚轮缩放；行星聚焦后 `← / →` 切换，`Esc` 返回，`Space` 坍缩／重生，`S` 进入太阳，`I` 手动切换资料卡。**触屏：**点按天体选择，总览单指拖动旋转，双指缩放，行星聚焦后左右拨动切换。默认静音，主动开启声音后才创建音频上下文。

打开 [手势调试模式](https://alzat007.github.io/solaris/?debugGesture=true)，或在本地地址后加 `?debugGesture=true`，查看镜像骨架、左右手、姿势分数、几何有效性、五指状态、Pinch 阶段、双掌确认阶段、目标、场景、重入锁、冷却和渲染 FPS。`trackingConfidence` 仅表示关键点几何有效性，不是 MediaPipe 未提供的真实跟踪分数，也不是识别准确率。正式访问默认隐藏调试信息。再次点击摄像头按钮即停止追踪并释放资源。

开发服务器的 `/tests/gesture-lab.html` 提供合成 21 关键点回放，不使用摄像头，也不包含在生产构建中。实际识别体验仍需使用真人手势与设备验证。

完整的文件职责、状态机、阈值、优先级与调参说明见 [GESTURE_SYSTEM_V2.md](GESTURE_SYSTEM_V2.md)。

## 项目结构

- `src/scene`：太阳系组合、深空、轨道、屏幕与 3D 交互场映射。
- `src/planets`：Sun、八个独立行星组件、PlanetBase、表面材质、日珥、地球云层和月球、土星粒子环。
- `src/particles`：ParticleEngine 共享物理参数、GPU 粒子、组装与爆发 Shader、Big Bang 实例化光迹，以及坍缩螺旋光迹、吸积盘和能量核心。
- `src/gesture`：摄像头生命周期、稳定手身份、21 点特征提取、Pinch／保持状态机、互斥动作路由、光标、镜像预览、教程与 Debug。模型推理限制为 20Hz，光标由渲染循环继续插值。
- `src/interaction`：显式状态机、互斥动画时间线、轻量外部 UI 状态。
- `src/camera`：相机惯性、位置和四元数插值、冲击后坐。
- `src/audio`：本地合成的低频氛围、切换和爆发声。
- `src/performance`：平均帧率监测、持续低帧率降级。
- `src/ui`：最小 HUD、行星资料、手势提示和调试画面。
- `src/data/planets.ts`：真实数据与视觉半径、轨道尺寸分离。

## 性能与范围

HIGH 静态分配约 27 万主粒子，其中太阳 9.5 万、星尘 11.5 万、土星环 6 万；Big Bang 另有最多 1.8 万 GPU 实例化光迹。坍缩特效独立使用最多 1.2 万 GPU 实例化光迹与两张 Shader 平面，MEDIUM／LOW 分别显示 6,500／2,400 条。MEDIUM 使用一半主粒子，LOW 使用约 5.4 万。连续平均帧率低于阈值时依次降低 drawRange、DPR 与 Bloom，避免逐帧重写粒子。DPR 上限 1.5。粒子运动使用解析 Shader 物理场，属于可实时响应的艺术模拟，不是 N 体天体力学。

地球使用本地日照/夜景贴图，其他星球为程序化 Shader。星球尺寸、距离和时间流速均为艺术比例。气态行星的卫星发现数量持续变化，资料 HUD 使用“多颗”或“至少”标记。

双手动作的识别依赖光照、手掌可见程度及检测稳定性。真实手势准确率及 iPhone Safari / Android Chrome 的实际设备帧率需要在对应设备上验证。

## 隐私与资源

视频仅在浏览器内处理，不录像、不持久保存、不上传。MediaPipe 模型和 WASM 均从本站加载；首次安装后无需依赖模型 CDN。`postinstall` 会把与依赖版本一致的 WASM 复制到 `public/mediapipe`。字体通过 Google Fonts 请求；无法联网时自动使用系统字体。

- MediaPipe Hand Landmarker：Google 官方 float16 模型，`public/models/hand_landmarker.task`。
- Earth day / night：Three.js r160 examples 的 `earth_atmos_2048.jpg` 和 `earth_lights_2048.png`，来源 https://github.com/mrdoob/three.js/tree/r160/examples/textures/planets 。
- 原始素材与第三方许可证信息见 `THIRD_PARTY_NOTICES.md`。

WebGL 上下文丢失、渲染初始化/Shader 故障会显示可恢复提示；摄像头拒绝、缺失或模型失败会进入鼠标模式，不阻断作品。
